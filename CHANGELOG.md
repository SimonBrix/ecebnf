# Change Log

All notable changes to the "ecebnf" extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)

## [0.1.3] - 2025-05-11
### Changed
- Changed the end capture in C++ string literal to have a _ after the end of the string.

## [0.1.2] - 2025-05-11
### Changed
- Changed the icon to use white background instead of transparent.
- Updated the readne to the new string literal syntax.

## [0.1.1] - 2025-05-09

### Changed
- Changed the c++ string literal syntax to R"ecebnf(...)ecebnf"_xxxx.

## [0.1.0] - 2025-04-15

### Added
- Syntax highlighting inside of R"(...)"_ecebnf strings in C++.

## [0.0.1] - 2025-04-14

### Added
- Initial release of ECEBNF extension for Visual Studio Code.
